# TransReser

> Historical / Academic Project — not recently verified

TransReser is a 2023 Symfony reservation application with customer, vehicle,
reservation, dashboard, and authentication workflows.

## Technology

- PHP 8.1 or newer
- Symfony 6.2 and Twig
- Doctrine ORM and migrations
- PHPUnit and Symfony test tooling
- Bootstrap-based frontend assets

## Local setup

Install dependencies with `composer install`, configure a local database in an
untracked environment override, apply the Doctrine migrations, and start the app
with the Symfony local server or another PHP web server.

The project has not been recently verified against current dependencies or a
fresh database. The tracked `.env` contains local/template values; do not commit
real credentials.

## Status and licensing

The repository is retained for historical reference. `composer.json` declares
the project proprietary; no separate open-source license is granted.
